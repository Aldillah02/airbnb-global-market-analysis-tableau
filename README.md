# Airbnb Global Market Analysis | Tableau

## Project Overview
This project analyzes Airbnb listing data across multiple countries to explore listing distribution, pricing patterns, ratings, and geographic trends.

The goal of this project is to transform raw Airbnb data into an interactive Tableau dashboard that provides a clear overview of the global Airbnb market.

## Dashboard Preview
The dashboard includes key metrics and visualizations covering:

- Total Listings
- Average Listing Price
- Average Rating
- Total Countries
- Top Countries by Number of Listings
- Top Countries by Average Listing Price
- Relationship Between Price and Rating
- Distribution of Listings by Price Range
- Geographic Distribution of Airbnb Listings

## Key Insights

- The dataset contains 12,805 Airbnb listings across 119 countries.
- India has the highest number of listings, with 2,779 listings.
- Italy and Greece are also among the countries with the largest number of listings.
- Listing prices show a wide distribution, with most listings concentrated in the lower price ranges.
- Canada, Australia, and Iceland appear among the countries with the highest average listing prices in the dataset.
- Most listings have relatively high ratings, with observations concentrated toward the upper end of the rating scale.

## Tools Used
